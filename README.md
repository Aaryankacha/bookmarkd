# ✨ Overview

Bookmarkd is a modern social platform built for readers.

Inspired by platforms like **Letterboxd**, **Goodreads**, and **AniList**, Bookmarkd allows users to discover books, manga, and manhwa while tracking their reading progress and interacting with a community of readers.

The application combines a beautiful editorial interface with real-time social features to create a premium reading experience.

# 🔐 Environment Variables

Create a `.env` file inside the backend.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_long_random_secret

NODE_ENV=development
```

# ⚙️ Installation

## Clone

```bash
git clone https://github.com/aaryankacha/bookmarkd.git

cd bookmarkd
```

---

## Install Frontend

```bash
cd client

npm install
```

---

## Install Backend

```bash
cd backend

npm install
```

---

## Run Backend

```bash
npm run dev
```

---

## Run Frontend

```bash
npm run dev
```
